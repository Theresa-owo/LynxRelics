设计基准 v0.2 · 2026-10-25。正在以 Kotlin 主体＋Java 薄 Mixin 实现 Java 26.3 / Fabric / JDK25 双端 Mod，采用 GPL-3.0-or-later。当前是开发原型，完整设计范围尚未实现，也未发布正式版本。已构建和实际验证的范围见[验证记录](docs/VALIDATION.md)，最新续接状态见[实现检查点](docs/plans/implementation-20261025.md)。

源码仓库：[Theresa-owo/LynxRelics](https://github.com/Theresa-owo/LynxRelics)。当前为开发预览；不将概念图、粗模或注册条目当作完整玩法交付。

当前使用方式、技能触发与配置见[使用与配置](docs/使用与配置.md)。2026-10-26恢复开发后，已修正服务端旧姿态瞄准导致的项链落点问题及防御被动的PvP开关，并通过43/43隔离服组件检查；这不等同于完整客户端验收。

26.3独立blocks/items图集登记已补齐；新客户端已进入隔离Test世界，加载日志中的本Mod缺失纹理/模型警告为0。完整穿戴、持握、动作、龙战及双端全流程仍须实际验收，见[客户端加载记录](docs/validation/20261026-stage12-client-load.json)。

核心循环：获得原版遗珍 → 建造专用工作台 → 制作具有独特动作的装备 → 与新生物互动或挑战精英 → 末地采矿与锻造 → 解锁长期便利装备。

## 本次明确采用的规则

- 龙蛋按服务器可量产处理，不以唯一性或稀缺性作为核心门槛；普通玩家也不需要刷物品机器才能开始路线。
- 无限烟花与无限珍珠为真正不消耗本体、不需要补充弹药的单件物品，使用频率、制作阶段和作用方式受限制。
- 三条路线均可独立开始；跨路线材料只用于最终便利物品和高阶锻造。
- 新末地矿物用于在锻造台升级已有护甲和工具，原有装备投入需要保留。
- 本Mod只有界铸四件护甲进入原生护甲槽；龙/回响/潮汐分别为Necklace、Belt、Gauntlet、Cloak四饰品套。原版护甲、持握武器与独立鞘翅栏保留各自职责。
- 界铸外观保持原下界合金轮廓，仅作克制末影紫强化，不属于饰品。
- 新生物围绕本文装备数值设计。生产服超限附魔和特殊定制装备另列配置档，不宣称已经完成实物适配。
- 项目作为独立的内容 Mod，客户端和服务端共同安装。具体 Minecraft 版本及加载器在实现前核定，不沿用旧管理 Mod 的兼容结论。
