# 使用与配置

当前适用版本：Minecraft Java 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0+26.3、Java 25。LynxRelics是双端内容Mod，客户端与服务器均需安装同一版JAR。Kotlin运行库已打入JAR；不要求额外安装Fabric Language Kotlin。业务使用Kotlin，Mixin保留Java薄注入。

这份说明描述当前实现；完整设计仍见design/00–08。构建、服务端组件检查与实际客户端验收分别记在[验证记录](VALIDATION.md)。

## 装备与按键

原版四护甲栏保持原有用途，界铸护甲放对应护甲栏。新增饰品只有项链、腰带、护手、披风四槽，每槽一件；允许混搭。饰品的基础护甲、韧性和击退抗性为0，套装只统计四个饰品槽。界铸装备、手持武器和鞘翅不计入饰品套装。

鞘翅由实际Equinox Elytra Slot 1.2管理，既不属于披风栏，也不由本Mod复制管理。当前兼容基准是用户提供的`elytra-slot-1.2.jar`，不是其它同名Trinkets/Curios适配。

| 默认操作 | 功能 |
|---|---|
| K | 打开四饰品栏，查看燃息、潮势与龙压 |
| G | 护手主动；龙喉手甲需要按住 |
| 潜行＋G | 项链主动；归巢龙印看向近处磁石时绑定 |
| V | 主手武器/海螺主动；副手持盾时仍可使用 |
| H | 龙翼披风空中扑翼；也保留再次按跳跃触发 |
| 原版使用键 | 装备空槽饰品、正常拉弓/举盾，或使用手持遗珍 |

所有新键均可在原版控制设置中重绑定。腰带、守藏护手、薄鸣披风和潜潮披风主要是被动装备，不依靠V或G释放。右键装备时，已占用的饰品槽会提示打开饰品栏更换。

## 三条路线的动作

下表为未专精、未附魔的默认值；专精与附魔的最终效果显示在对应物品Lore中。

| 装备 | 如何触发及用途 | 默认代价与限制 |
|---|---|---|
| 龙喉手甲 | 按住G蓄力0.75秒，随后喷吐2.4秒；提前松开取消 | 7格60度锥形，6段各4伤害；8燃息、龙压＋18、10秒冷却 |
| 归巢龙印 | 看向4.5格内磁石潜行G绑定；其它位置潜行G吟唱返回 | 同维度，6秒，12燃息、300秒冷却；移动或受伤中断 |
| 龙翼披风 | 空中H或再次跳跃扑翼；滑翔中为短转向修正 | 一次离地一次，稳定着地0.5秒重置；普通8燃息、滑翔4燃息，8秒冷却 |
| 缚龙腰带 | 装备后扩大燃息容量 | 40→50；不自动生产燃息 |
| 裂界之刃 | 使用键或V蓄力0.6秒后自动向前突进 | 最多6格、3目标各12伤害；10燃息、龙压＋25、12秒冷却 |
| 鸣纹项链 | 潜行G，在当前视线落点产生短暂调查声源 | 2秒声源、12格范围、16秒冷却；同时延长储响2秒 |
| 守藏护手 | 配合盾牌，首次举盾后短窗口迎击敌对攻击 | 基础招架窗口0.30秒，6秒冷却；普通盾可招架，回声盾可花储响反击 |
| 回声盾 | 正常举盾精准招架；有储响时潜行重新举盾，释放3格盾击 | 储响最多6、保留8秒；盾击为4＋储响，上限10，8秒冷却、额外12耐久 |
| 余响长弓 | 正常使用键拉弓、松开射击；潜行搭配余响箭射向方块表面产生诱饵 | 需要箭；特殊声源6秒、冷却4秒，不造成伤害；普通射击保留伤害 |
| 寂静束带 | 在地面连续潜行0.6秒，进入脚步消音 | 最多6秒或6步，冷却18秒；停止潜行、奔跑、受伤或离地结束 |
| 薄鸣披风 | 受到敌对直接近战伤害时，自动留下2秒残响 | 20秒冷却；不清除近身战斗或首领仇恨 |
| 水镜项链 | 普通箭将命中时潜行G，开启0.25秒反射窗口 | 成功40潮势、12秒冷却；失误5潮势、3秒冷却；只反射一枚普通箭，伤害上限8 |
| 潮引护手 | 按G，5格锥形潮引 | 最多3目标各6伤害，牵引最多1格；25潮势、10秒冷却 |
| 潮锋戟 | 使用键或V蓄力0.6秒后释放浪锋；潜行使用改为冲行 | 浪锋8格、最多3目标各10伤害，25潮势、8秒冷却；冲行6格、40潮势、12秒冷却，需地面或水中 |
| 潮音海螺 | 眼部入水后使用，显示水下物品及水母声纹6秒；潜行使用吟唱返回记录水面 | 探物24格、15潮势、12秒冷却；回程吟唱4秒、25潮势、90秒冷却，范围96格/高度差64格 |
| 潜潮腰带 | 装备后扩大潮势容量，正常空气耗尽后使用储备空气 | 潮势100→120，额外空气20秒；离水逐渐补充空气 |
| 潜潮披风 | 受到有效敌对战斗伤害时自动展开潮罩 | 40潮势，最多吸收4点，20秒冷却；不处理虚空、饥饿或自伤 |

声源会引导僵尸、骷髅、苦力怕及裂隙潜猎者调查，不会强制清除首领或6格内正在交战目标的仇恨。技能默认只攻击敌对生物，牲畜、盔甲架、友军和宠物不能用来测试攻击技能或刷潮势；PvP和伤害被动生物分别由服务器配置控制。

龙精粹使用后补充20燃息，已满时保留物品。持有任一潮汐武装（含副手）或穿戴潮汐饰品时，水下每秒＋5潮势、淋雨每秒＋1，有效普通近战命中每秒最多＋3；环境收益不叠加。四件潮汐套的水下恢复为每秒6。

创造模式默认自动补足资源，便于试用主动技能，冷却和环境条件仍生效。精准招架、箭矢反射和受伤被动建议在生存模式使用敌对生物验证。实际失败原因会显示在动作栏，例如资源不足、冷却、没有水面记录、超距、未入水或已有技能吟唱。

## 界铸、永续用品与原版扩展

界铸采用原版下界合金版型和紫色主体材质，仍按原生护甲/手持物品使用。当前界铸斧总攻击11、攻速1.2；剑总攻击9、攻速1.8。五种界铸手持武装近战改为魔法伤害，绕过护甲，仍受保护附魔及抗性效果影响。界铸护甲每件减少8%受支持魔法伤害，四件合计上限32%；只算实际四护甲栏，不附带物理或摔落减伤。

永续烟花冷却0.75秒，滑翔时助推，地面使用仅装饰火花；缚界珍珠冷却5秒，保留正常传送伤害，同时最多一枚在途、最长15秒。两个物品均不耗本体、不需要补弹，所有副本与双手按玩家共用各自冷却，重连保留；珍珠不用于跨维度或强制加载远处落点。

激流可在干燥晴天使用。引雷不再要求雷雨，仍保留目标版本原生的露天/目标条件。变速铁轨右键循环4/8/16/24格每秒，潜行反向循环，弯道限速8；实际矿车线路与客户端行为仍列在验收清单中。

## 配方与配置

完整配方编号、材料、输出、加工时间见[配方索引](recipes-index.json)；16种附魔见[附魔索引](enchantments-index.json)与[第08章](design/08-附魔扩展.md)。三工艺台内的目录由服务器发送，支持名称/编号搜索、悬停材料/催化物/返还说明。催化物保持可回收；输出容不下时不提交扣料。原版合成、锻造、冶炼使用原生配方路径。

启动后生成`config/lynxrelics/balance.json`。当前171个键；缺少的新键自动补入默认值，未知键和非法数值会明确报错，修改后需重启。服务器决定伤害、资源、冷却、掉落与工艺。涉及注册时装备属性、耐久及本地物品说明的配置，测试或联机时应在客户端与服务器保持一致。

| 参数组/键 | 含义/单位 |
|---|---|
| `dragon.enabled`、`echo.enabled`、`tide.enabled` | 各路线开关，0关闭、1开启 |
| `skills.pvp`、`skills.hurtPassive` | 主动技能的PvP/被动生物目标开关，默认均0 |
| `skills.creativeFreeResources` | 创造模式资源补足，默认1 |
| `breath.*`、`tide.*` | 容量、费用、范围、伤害、龙压和部分冷却；名字含Ticks/Cooldown的时间以tick计，20tick为1秒 |
| `infinite.fireworkCooldown`、`infinite.pearlCooldown` | 默认15/100tick，共同持久冷却 |
| `infinite.pearlLifetime` | 默认300tick，在途寿命上限 |
| `forging.durabilityMultiplier` | 原生耐久乘数，默认1.25，向上取整 |
| `forging.axeAttackDamage`、`forging.axeAttackSpeed` | 斧的总攻击和每秒攻击次数，默认11/1.2 |
| `forging.swordAttackDamage`、`forging.swordAttackSpeed` | 剑的总攻击和每秒攻击次数，默认9/1.8 |
| `forging.magicDamage` | 界铸近战魔法伤害开关，默认1 |
| `forging.magicResistancePerPiece`、`forging.magicResistanceCap` | 护甲逐件/总计魔法减伤比例，默认0.08/0.32 |
| `craft.*` | 工艺开关和时间乘数 |
| `raid.*` | 强化龙开关、预警/技能/召回/治疗预算及掉落；原版龙最大HP固定3000 |
| `mob.*` | 七种生物属性、生成权重、照料/生产、仪式与独立路线Boss参数 |
| `ore.*` | 矿脉开关、外岛半径、概率、Y区间与矿团大小 |
| `rail.*`、`trident.*` | 铁轨档位/加速度及晴天三叉戟功能 |
| `lodestone.*`、`beacon.*`、`resonator.*` | 据点配件、信标核心、共鸣匣的范围、速率和燃料等 |
| `render.hideCloakGliding` | 滑翔时隐藏本Mod披风翼片，让独立鞘翅展开 |

尚有个别路线武器/专精常数未全部抽入配置；本表不声称设计的每个数值都已配置化。

## 隔离客户端手测

项目通过`gradlew.ps1 runClient --console=plain '--args=--graphicsBackend vulkan --username RelicsTester --quickPlaySingleplayer Test'`启动项目内Test世界。窗口交给用户操作，不连接生产服务器，不替换Lunar安装。

开发环境提供`/relicstest`准备基础龙系装备、武器与独立鞘翅；`/relicstest workshop`准备萃取台；`/relicstest status`查看服务端实际收到的按键、资源、动作状态及最近失败/成功提示。这些命令不在普通安装JAR的运行环境注册。

当前待实际确认：中英语言切换、穿戴版型/头盔开口、方块与持握材质、上下弓臂拉弦、技能命中/反馈、完整阶段龙战，以及死亡/重生/keepInventory/重连/维度/满背包/Shift装备/鞘翅损坏修复与披风共存全流程。服务端43项组件通过不代替这份客户端验收。
