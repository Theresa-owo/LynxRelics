# 第三轮物品图标

针对“粗糙、没有原版质感”的反馈，继续使用内置imagegen逐件制作。运行目标64×64，源PNG保存在assets/icons/source，透明度和哈希由compile-icons.mjs检查。原图、旧版修订和原概念图保留；不把概念板直接裁为运行资产。

本轮主题包括三种工艺台、巡航焰匣、三系十二件饰品和潮音海螺。统一要求清楚的小尺寸轮廓、左上高光、右下暗面、3至5档色阶，区分金属、玻璃、布料、皮革、骨质与铜锈；不使用平涂符号、模糊渐变、背景框或发光云。每次输出单件透明图。

长弓v3是在v2源上针对性加粗弓弦，保留弓身和材质，以64px预览确认不丢失。界铸四护甲以本地SDK中的原版下界合金缩略图作版型参考，以最新紫色概念图作色彩参考，约70%可见金属面为紫黑/深紫/紫晶。参考原版PNG只在被忽略的.local/art-reference中，不作为新源文件提交。

本轮只确认图源和运行尺寸观感；穿戴/持握模型、UV贴图和实际客户端加载分别验收，不用精细缩略图掩盖灰模状态。
