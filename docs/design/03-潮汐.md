# 潮汐路线

v0.2：饰品槽、单件/套装加成及Elytra兼容以[第06章](06-四饰品栏与Elytra兼容.md)为准。

## 定位与解锁

潮汐负责水下探索、水陆衔接和蓄势战斗。海洋之心作为调压台的可回收催化核心；鹦鹉螺壳作为可持续消耗材料，也可由新生物产出的潮珠替代。

流程：调压台 → 凝潮珠 → 潮铸铜 → 基础装备 → 潮灯水母/礁背潜伏者 → 专精 → 丰饶信标与永续核心。

## 潮势

持有或装备任一潮汐装备时，玩家共享0–100潮势：全身入水每秒+5，淋雨每秒+1，正常有效近战命中每秒最多+3。优先取环境收益，不叠加入水与雨。不能靠攻击友军、宠物、盔甲架或自己充能。

离开水域5秒后，每秒自然减少1。换装备不会得到第二条潮势，也不会重置技能冷却。潮势是战斗状态，凝潮珠主要用于制造和据点燃料，不需要每次技能吃一颗。

## 潮锋戟

- 基础伤害8、攻速1.0、耐久768；近战作用距离设计为3.5格，需在目标版本验证实际判定和动画。
- 右键蓄力0.6秒，消耗25潮势，发出8格、宽1.5格的浪锋，最多命中3个目标，每个伤害10，减速20%持续2秒，冷却8秒。
- 浪锋遇实体方块停止，不生成水源，不冲散掉落物，不改变红石或作物。
- 潜行右键消耗40潮势，沿地面/水面向前冲行最多6格，冷却12秒；不能在空中无限接力。
- 两种主动技能共用一次使用后的2秒短锁定。
- 专精A“远潮”：浪锋10格，目标仍3。专精B“奔潮”：冲行8格，消耗仍40。

## 潜潮披风

- Cloak饰品槽，护甲/韧性0、耐久528，不占胸甲或独立鞘翅栏。
- 20秒额外空气储备转由潜潮腰带提供，本披风不重复叠加；合并后的额外储备上限60秒。
- 潮势至少40且受到有效战斗伤害时，自动花费40形成潮罩，吸收本次最多4点伤害，冷却20秒。它不处理虚空、饥饿或自伤。
- 原生伤害事件被其它系统取消时不扣资源；不会把吸收量变成可循环触发的攻击伤害。
- 专精A“深潜”：额外储备30秒，总额外上限仍60。专精B“稳潮”：潮罩冷却16秒，吸收仍4。

## 潮音海螺

- 耐久384，每次成功主动能力损耗2；被取消且未生效时不扣完整耐久。
- 右键消耗15潮势，发出24格水下探物声纹，持续6秒，只突出显示水中的可拾取掉落物和本Mod潮灯水母，冷却12秒。
- 不读取容器内容、不显示矿物、不标记其他玩家。客户端音效关闭仍有声纹可见。
- 潜行右键可回到最近一次进入深水时记录的安全水面点：距离最多96格、垂直差最多64格、同一维度，吟唱4秒，花费25潮势，冷却90秒。
- 只保留一个记录，进入新的水域后更新。移动超过0.15格或受伤中断；落点不合法则拒绝，不把使用者塞进船体、方块或岩浆。
- 专精A“寻流”：探物半径32，持续仍6秒。专精B“返潮”：回程冷却60秒，距离仍96。

## 水镜项链

- 耐久384，每次成功反射损耗2；可用潮铸铜按通用规则维修。
- Necklace饰品槽，用项链技能键激活反射；不是持续举盾，不能阻挡普通近战。
- 对一次可反射的普通箭矢，右键在0.25秒窗口内触发反射，消耗40潮势，冷却12秒；反射后的原始伤害上限8。
- 不反射激光、区域攻击、爆炸、已反射弹射物或Boss专用攻击。失误消耗5潮势，进入3秒短冷却。
- 专精A“明镜”：窗口0.3秒。专精B“回光”：消耗35，窗口仍0.25秒。

## 水母与礁背潜伏者

潮灯水母在海底缓慢游动，喂海带后每10分钟正常加载活动产潮珠1，存量达到2停止。潮珠给T03提供替代原料；玩家不必大量猎杀水母。

礁背潜伏者是海底精英，正面硬壳会减伤，抬钳前有清晰预警，攻击时暴露侧后。击败掉落潮纹壳1，解锁专精，不作为基础装备门槛。它的完整数值和掉落见生物章节。

## 阶段预算

潮锋戟需要潮铸铜4，即凝潮珠8，需要精炼两批：鹦鹉螺壳或水母潮珠共2、海晶碎片8、干海带16、水桶循环使用；另需制铜的铜锭8，以及配方直接用的铁锭2和木棍1。

玩家可以选择寻找壳、狩猎海洋精英或照料水母，各自产出的资源承担不同用途。
