# 四个饰品栏 装备加成与Elytra兼容

v0.2权威规则：本章替代v0.1中龙翼占胸甲、寂静靴占鞋子、潜潮背甲占胸甲以及水镜占副手的规定。原版护甲不受禁用；本Mod新增护甲只有下界合金升级出的界铸四件套使用原生护甲栏。

## 1. 装备结构

| 容器 | 槽位 | 允许物品 |
|---|---|---|
| 原生护甲 | 头盔、胸甲、护腿、鞋子 | 原版护甲、对应部位的界铸护甲 |
| LynxRelics饰品 | Necklace、Belt、Gauntlet、Cloak各1格 | 对应类型的路线饰品，合计4件 |
| Elytra Slot | 原Mod拥有的独立鞘翅格 | 原Mod允许的鞘翅；不是Cloak格 |
| 原生主/副手 | 原有持握槽 | 剑、弓、戟、盾、海螺等持握用品 |

Gauntlet是一个饰品物品，渲染为一只或一对护手，不占主/副手。四件饰品均不提供基础护甲、韧性或击退抗性；主动动作、资源容量和条件效果承担价值。

## 2. 龙精粹饰品套装

| 槽位与物品 | 单件加成/技能 | 代价 |
|---|---|---|
| Necklace 归巢龙印项链 | 绑定磁石，同维度吟唱6秒返回；专精可4秒或冷却240秒 | 12燃息，默认冷却300秒；移动/受伤中断 |
| Belt 缚龙腰带 | 燃息上限40→50；不自动生产燃息 | 无额外伤害，卸下时超过40的部分截断 |
| Gauntlet 龙喉手甲 | 蓄力0.75秒，7格60度喷吐2.4秒，6段各4伤害 | 8燃息、龙压+18、冷却10秒；喷吐减速25% |
| Cloak 龙翼披风 | 空中再按跳跃扑翼一次；水平冲量0.8、向上0.42 | 8燃息、龙压+15、冷却8秒；稳定落地才重置 |

龙喉手甲不再增加裸手基础攻击，不能在饰品格叠加原来的5点手持武器伤害。裂界之刃仍是主手武器，原技能保留。

2件：龙系技能的龙压积累减少10%。4件：每20秒，下一次龙系主动技能的燃息消耗减少2，最低消耗2；不直接增加伤害。

## 3. 回响饰品套装

| 槽位与物品 | 单件加成/技能 | 代价 |
|---|---|---|
| Necklace 鸣纹项链 | 储响保留时间+2秒；激活可在12格内发出一次2秒调查声源 | 激活冷却16秒；首领不受强制诱导 |
| Belt 寂静束带 | 潜行0.6秒后消音，最多6秒/6步 | 冷却18秒；奔跑、离地、受伤结束；不抹掉攻击或破坏声 |
| Gauntlet 守藏护手 | 使用盾牌时精准招架窗口额外+0.05秒，上限0.30秒；成功招架最多储6点反击值 | 招架仍有6秒共享冷却，不能与回声盾重复储两份 |
| Cloak 薄鸣披风 | 受到敌对直接伤害后，留2秒无碰撞残响，供适配普通怪物调查 | 冷却20秒；不对玩家隐身，不清空Boss仇恨 |

2件：余响箭声源持续时间+1秒，上限12秒。4件：成功精准招架可缩短当前一项回响主动技能剩余冷却2秒，每8秒最多一次；不缩短精准招架本身冷却。

| Belt 潜潮腰带 | 潮势上限100→120，额外水下空气储备20秒 | 额外空气总上限60秒；卸下时潮势截断到100 |
| Gauntlet 潮引护手 | 5格锥形潮引，最多3个敌对目标各6伤害，牵引最多1格 | 25潮势、冷却10秒；默认不牵引玩家，不穿实体方块 |

潮锋戟和潮音海螺保留主手用品。潜潮披风不再提供原背甲的6护甲/1韧性，空气储备移至腰带；水镜从副手移动到项链，因空出手而把费用35→40、冷却10→12秒。

## 5. 新增配方与旧配方映射

原D07、D09、D10分别产出Gauntlet、Cloak、Necklace；E07产出Belt；T06产出Cloak；T08产出Necklace。材料不变，模型、槽位和加成按本章。

|---|---|---|
| A01 | 缚龙锭2、皮革4、龙精粹1 | 缚龙腰带1 |
| A02 | 鸣骨2、紫水晶碎片4、线2 | 鸣纹项链1 |
| A03 | 鸣骨2、铁锭2、皮革2 | 守藏护手1 |
| A04 | 鸣骨2、幻翼膜2、羊毛4 | 薄鸣披风1 |
| A05 | 潮铸铜2、皮革4、鹦鹉螺壳1 | 潜潮腰带1 |
| A06 | 潮铸铜2、铁锭2、海晶碎片2 | 潮引护手1 |

新饰品的耐久初值：龙腰带384；鸣纹项链384、守藏护手512、薄鸣披风432；潜潮腰带384、潮引护手512。原转换物品沿用其合理耐久，归巢项链依旧无耐久。触发条件效果/成功主动技能才损耗，固定容量加成不按tick磨损。维修和专精沿用各系规则；新件专精先复用基础版本，不临时增加未经定义的分支。

## 6. 套装与操作

允许混搭，例如2龙+2潮；每件只按其实际占用的一个槽计数，同一物品不能同时占两个槽。4件套要求四个不同部位均为同路线，鞘翅、武器和界铸护甲不计数。

V保持“主手武器技能”，新增可重绑定G为“Gauntlet技能”，Shift+G为“Necklace技能”。Belt主要为被动，Cloak为手势或条件触发。原生右键优先交互和副手防御，按键冲突在设置中提示，不覆盖玩家旧绑定。披风/腰带的被动不能因切换热栏或开关页面重复触发。

## 7. Elytra Slot兼容边界

本地核对对象是 `E:/Minecraft/Lunar/mods/fabric-26.3/elytra-slot-1.2.jar`，mod id为`elytra-slot`、版本1.2，其依赖声明只有Fabric Loader/Fabric API及Minecraft/Java版本，没有声明Trinkets/Curios。元数据中仍有示例项目来源链接，不能把它当作准确源码地址。

公开同名项目描述了独立鞘翅槽、悬停展开和生存/创造背包交互：[Elytra-Slot项目页](https://modrinth.com/project/elytraslot)。本地文件和发布页面的兼容范围描述不完全相同，实现以实际安装JAR及游戏验证为准。

设计采用独立的Lynx饰品页面/侧页入口，数据标识为necklace/belt/gauntlet/cloak，默认各1。保留原InventoryMenu槽位含义，不抢用现有elytra/cape标识，不假设其具体槽位数字，不直接改写它的快捷装备或耐久逻辑。

龙翼披风与鞘翅可同时装备：未滑翔时可触发一次扑翼；已经鞘翅滑翔时，不再给予第二套持续升力，只提供消耗4燃息、冷却8秒的短促转向修正。火箭助推、鞘翅耐久和是否能滑翔继续由原有鞘翅系统决定。

滑翔时默认收起/隐藏Lynx披风翼片，原鞘翅仍可见；该外观选项可配置，不能删除实际饰品属性。玩家原有皮肤披风、YSM和鞘翅皮肤渲染不得被无条件覆盖。

本章是兼容设计，不是已完成兼容验证。实现必须实测：生存/创造页面、Shift点击、右键装备、死亡/重生/keepInventory、重连/维度切换、背包满格、鞘翅损坏与修复、披风同时穿戴、滑翔与火箭，以及常用模型Mod。
