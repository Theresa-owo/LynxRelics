# 龙精粹路线

v0.2：饰品槽、单件/套装加成及Elytra兼容以[第06章](06-四饰品栏与Elytra兼容.md)为准。

## 定位与解锁

关键词为爆发、位移和可控的空中机动。基础工艺需要到过末地并获得龙息；龙蛋按可量产处理。普通玩家只需一枚作为可回收催化物，复制得到的多余龙蛋可用来提高生产效率，不能直接换成毕业装备。

流程：萃取台 → 龙精粹 → 缚龙锭 → 基础装备/幼灵 → 专精 → 失巢龙裔 → 界铸与永续用品。

## 使用资源

玩家燃息上限40。手持龙精粹使用可补充20燃息；满值时不消耗物品，部分溢出前给出提示。燃息由玩家持有，不随换装备复制。

龙压范围0–100，技能积累龙压；停止使用技能3秒后每秒下降8。到100进入6秒过载，龙系主动技能暂停，结束降至60。过载不直接扣血，界面应提前提示。它约束连续切换多件龙系装备的爆发。

## 装备

### 龙喉手甲

- Gauntlet饰品槽，耐久512，不增加裸手基础伤害，不占主/副手。
- 右键蓄力0.75秒，随后喷吐最多2.4秒。射程7、锥角60度，每0.4秒最多结算一次，共6次，每次原始伤害4。
- 一次完整喷吐消耗8燃息，龙压+18，结束后冷却10秒；释放或中断时按已发生段数扣资源。
- 喷吐期间移速降低25%，不穿透实体方块，不伤害同一目标的多个碰撞部件来重复计数。
- 不生成火、不破坏方块，不把龙息伤害设为无视护甲。
- 专精A“长流”：射程9，伤害不变。专精B“聚焰”：锥角35度，每段伤害×1.2。

### 裂界之刃

- 基础伤害8、攻速1.2、耐久768。
- 右键蓄力0.6秒，向准星方向进行最多6格的短冲刺，对路径最多3个敌人各结算一次12点伤害。
- 消耗10燃息，龙压+25，冷却12秒；命中与否均进入0.35秒恢复，不能同时立刻举盾。
- 路径与身体空间逐段检查，遇阻在合法位置停下，不穿墙、不越世界边界，不提供全程无敌。
- 专精A“穿阵”：目标上限5。专精B“返身”：距离4，冷却9秒。

### 龙翼披风

- Cloak饰品槽，基础护甲0、耐久432；鞘翅使用独立Elytra Slot，二者可同时装备。滑翔时扑翼改为短促转向修正，细则见第06章。
- 生存/冒险中，空中再次按跳跃触发扑翼。水平冲量上限0.8、向上冲量0.42，单次作用约0.6秒，具体速度曲线以原型校准。
- 消耗8燃息，龙压+15，冷却8秒；每次离地只可触发一次，稳定落地0.5秒才重置机会。
- 保留创造、旁观和其它来源的原生能力，不能反复装备重置扑翼。
- 专精A“翔升”：向上冲量0.55。专精B“定向”：水平冲量1.05。

### 归巢龙印项链

- 无耐久损耗，不消耗本体，由燃息、吟唱和冷却约束。
- 对磁石潜行使用，绑定一个据点；新绑定覆盖旧绑定并清楚反馈。仅能回同一维度。
- 使用时吟唱6秒，消耗12燃息，冷却300秒。移动超过0.15格、受伤、死亡或目标失效中断。
- 只在传送成功后扣完整费用和进入完整冷却；故意中断有3秒短冷却。
- 目标仍需存在磁石、可访问、可加载且有合法身体空间。不会强行落入岩浆或生成平台。
- 专精A“行军”：吟唱4秒。专精B“安稳”：冷却240秒。

## 龙息幼灵与材料循环

胚晶放置后生成一只幼灵，每玩家同时最多拥有1只，体型约0.5格。它不攻击；在4格内帮助拾取允许主人取得的地面物品，要求视线畅通，每分钟最多拾取8个物品实体，不打开容器、不加载远处区块。

喂食紫颂果可回复4 HP。最近得到喂养、且在正常加载的区块中活动15分钟后脱落蜕龙鳞1；地面/待领取存量达到2时暂停生产。也可从裂隙潜猎者战斗获得鳞片，避免专精只能挂机等待。

## 阶段预算

一把裂界之刃需要8龙精粹制造4缚龙锭，即标准萃取2批、龙息16瓶，再加钻石2和木棍1。增效路线同样需要两批才能满足首次制作，但会剩余4精粹用于补充燃息或后续装备。

龙蛋量产提供粉末和效率，主要投入仍是龙息、工艺材料、专精选择及实际冒险。最晚期永续核心还需要末地矿与Boss纹章。
