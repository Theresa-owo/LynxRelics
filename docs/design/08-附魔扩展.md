# 附魔扩展与叠加规则

## 获取方式

常规新附魔可通过附魔台、铁砧合书及明确的战利品表取得；稀有书通过路线精英/Boss材料的确定工艺制作。不是所有新附魔都塞进同一个随机池。

| 附魔/最高等级 | 适用物品 | 各级收益 | 互斥/上限 |
|---|---|---|---|
| 破界III | 剑、斧、近战戟 | 对末地敌对生物额外原始伤害+2/+3/+4 | 与锋利/亡灵/节肢系互斥，不对玩家额外增伤 |
| 回声II | 近战武器 | 充能至少90%的普攻留下10%/15%的迟发余响 | 2秒一次；余响不触发自身或其它命中附魔 |
| 导潮III | 近战武器 | 有效普通命中额外返1/2/3潮势 | 每秒最多一次，不对友军/自伤充能 |
| 长鸣II | 弓/弩 | 余响箭声源延长1/2秒 | 与其它来源合计最长12秒，不增加直接伤害 |
| 镇响III | 盾牌 | 精准招架窗口+0.02/+0.04/+0.06秒 | 与护手/专精合计最高0.35秒；与固守互斥 |
| 固守III | 盾牌 | 格挡击退再减少5%/10%/15% | 举盾额外减速3%/6%/9%；与镇响互斥 |
| 容息III | 缚龙腰带 | 燃息上限+4/+8/+12 | 该玩家最终上限64，卸下要截断，不能换带复制 |
| 蓄潮III | 潜潮腰带 | 潮势上限+5/+10/+15 | 该玩家最终上限140，不额外增加每秒收益 |
| 节律III | Gauntlet | 主动冷却缩短3%/6%/9% | 被动百分比冷却缩短总上限20%；不能直接刷新 |
| 归巢II | 归巢龙印项链 | 返回吟唱缩短0.5/1秒 | 吟唱总下限3秒，不移除中断条件 |
| 明镜II | 水镜项链 | 反射窗口+0.025/0.05秒 | 含专精总上限0.35秒，不扩展可反射攻击种类 |
| 余韵II | 鸣纹项链 | 储响再保留1/2秒 | 含专精总上限14秒，不增加伤害储存上限 |
| 缓冲III | Cloak | 摔落伤害降低5%/10%/15% | 本Mod新增同类摔落减伤总上限25%，再与原版分开乘算 |
| 巡航III | 实际装备的鞘翅 | 正常耐久损耗额外10%/15%/20%概率免除 | 与耐久附魔依次结算，只认一件实际飞行鞘翅 |
| 精炼II | 镐/斧等合适工具 | 50%/100%概率把白名单普通矿掉落直接转冶炼物 | 不给额外经验，额外损耗1耐久；与时运/精准采集互斥 |
| 寻脉II | 界铸镐 | 挖界髓矿后，提示8/12格内最近矿脉方向3/5秒 | 冷却8秒，仅已加载矿物索引，不整球高频扫描 |

精炼首批只适配普通铁/金/铜矿对应掉落，排除界髓矿、远古残骸及其它需专用工艺的材料。取消挖掘、保护拦截或未实际掉落时不额外生成物品。

## 书籍工艺

常规书籍工艺在各路线工作台选择目标附魔，不能用同一无序工作台配方隐式产出多种结果。

| 编号 | 位置与输入 | 输出 |
|---|---|---|
| N01 龙系基础书 | 萃取台：书1、龙精粹4、青金石4 | 选择破界I/容息I/归巢I的书1 |
| N02 回响基础书 | 调谐台：书1、回响尘4、青金石4 | 选择回声I/长鸣I/镇响I/固守I/余韵I的书1 |
| N03 潮汐基础书 | 调压台：书1、凝潮珠4、青金石4 | 选择导潮I/蓄潮I/明镜I的书1 |
| N04 通用饰品书 | 任一路线台：书1、对应精炼金属1、青金石4 | 选择节律I/缓冲I的书1 |
| N05 高级书工艺 | 对应路线台：本附魔I书1、龙心棱片1、对应路线精粹8 | 本附魔II书1；不直接越过最高等级 |
| N06 巡航/精炼/寻脉书 | 对应路线台：书1、界髓锭1、龙心棱片1、青金石4 | 选择巡航I/精炼I/寻脉I的书1 |

铁砧同级合书按目标版本原版经验与代价规则进行，最高等级不超过本表。N05只把I提升为II，III仍需正常合书；一级封顶附魔不允许套用该工艺。

## 防叠加约定

- 每件饰品最多容纳两种本Mod自定义附魔；原版耐久/修补是否适用按该物品实际耐久类型判断，无耐久项链不接受无效耐久附魔。
- 原版保护、荆棘等护甲附魔不因新增饰品槽自动多算四件；四个饰品不是额外四件护甲。
- 同一次攻击的直接伤害、延迟余响、龙息和反射分别标记来源，不能相互递归触发。
- 本Mod同类百分比增伤总上限20%；固定额外伤害同次只取最高一项，保留原版互斥。技能不默认复制主手全部附魔到每一段伤害。
- 护甲仍只有四件，界铸沿用原版可附魔类别；末地护甲不是Necklace/Belt/Gauntlet/Cloak。
- 巡航必须读取Elytra Slot实际提供飞行能力的物品，不能只扫描胸甲栏，也不能胸槽与独立槽重复享受。

本章定义玩法目标。具体附魔数据格式、目标版本注册接口、Elytra附魔读取链及跨Mod互斥需要在实现时核对与验证，不能仅因能合出书就宣称效果已经生效。
