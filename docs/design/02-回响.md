# 回响路线

v0.2：饰品槽、单件/套装加成及Elytra兼容以[第06章](06-四饰品栏与Elytra兼容.md)为准。

## 定位与解锁

回响负责招架反击、声源诱导与安静探索。找到一枚回响碎片即可作为调谐台的可回收催化核心，后续消耗常规材料。不会要求每把武器都消耗一枚不可再生的原版遗珍。

流程：调谐台 → 回响尘 → 鸣骨 → 基础装备 → 回声蛾材料/无声守藏者 → 专精与声学辅助。

## 回声盾

- 耐久672，普通举盾沿用原版盾牌的基本交互和可格挡伤害类别。
- 首次举盾后的0.25秒是精准招架窗口，窗口冷却6秒，频繁放下重举不会刷新。
- 一次成功精准招架记录本次实际被盾牌阻止的伤害，最多6点，保留8秒；不能累加多个储响。
- 潜行并重新举盾，消耗储响发动3格、70度盾击，伤害为4+储响，上限10，冷却8秒，额外消耗耐久12。
- 坠落、饥饿、虚空、自伤和友军伤害不能用于充能；是否接受玩家敌对攻击由PvP配置决定。
- 专精A“长响”：储存12秒。专精B“反震”：基础盾击5，储响上限仍为6。

## 余响长弓与余响箭

- 长弓耐久576，普通箭的蓄力、基础伤害和弹道沿用目标版本原版弓，再核对附魔相互作用。
- 装备余响箭并潜行射击，箭命中合法表面后形成6秒声源，每秒一次可见声纹。一次消耗余响箭1，特殊射击冷却4秒。
- 声源不造成伤害、不伪造玩家实体。第一批拟适配僵尸、骷髅、苦力怕及本Mod潜猎者的调查目标逻辑；首领和正在近身交战的目标不会被强制清空仇恨。
- 对原版振动监听生物，只能按实际版本允许的事件参与响应；不能承诺一支箭必定引走守卫者。
- 每位玩家最多同时存在1个诱饵，后一支替换前一支。与其它玩家的诱饵不形成无限来回切目标。
- 专精A“久响”：声源9秒，冷却6秒。专精B“偏音”：调查半径12变为16，持续仍6秒。

## 寂静束带

- Belt饰品槽，护甲/韧性0、耐久384，不占原生鞋子栏。
- 连续潜行0.6秒后进入消音，最多6秒或6次脚步，以先到者为准，冷却18秒。
- 效果仅处理装备者的步行脚步声与对应脚步振动；攻击、破坏、开容器、落水、奔跑和其它事件保持可感知。
- 在效果期间停止潜行、受伤或离地即结束。结束额外损耗耐久12，不提供隐身或气味免疫。
- 专精A“细步”：8次脚步，时间仍6秒。专精B“轻音”：冷却15秒，次数仍6。

## 共鸣匣

共鸣匣是可放置、可收回的据点装置。任意音乐唱片放入后保留，不随使用消耗；每份回响尘维持60秒。右键切换模式，同时显示清晰的图标与文字。

| 模式 | 半径与作用 | 限制 |
|---|---|---|
| 安抚 | 8格，安抚本Mod友善生物，使喂养/跟随更稳定 | 玩家攻击会打断；不解除已有敌意 |
| 振奋 | 8格，玩家及明确友军移动速度+5% | 同名效果不叠加，不提升攻击速度 |
| 干扰 | 8格，每5秒提供一次短声源供适配生物调查 | 不强迫Boss转向，不替代玩家仇恨 |

听音乐的音量服从客户端音量设置；模式效果与音量无关。停机、无燃料、区块卸载时停止生效；收回保留已装入唱片，不返还已经运行的燃料时间。

专精A“广域”：范围10，燃料每45秒一份。专精B“节流”：范围仍8，每90秒一份。一次只选一种。

## 生物与后续成长

回声蛾是友善引导生物，喂发光浆果后，在加载区块中活动8分钟脱落薄鸣鳞1，待领取达到2时停止。击杀不提供鳞片，玩家可选择引导和照料路线。

无声守藏者掉落守藏纹片1，用来解锁调谐台的专精工艺；纹片作为催化物保留，可与同伴共享工作台。它是路线专精门槛，不阻挡基础盾、弓和靴的制作。

## 阶段预算

一面回声盾需要鸣骨3，即回响尘6。E02加工两批得到8尘，余下2尘可再制作鸣骨或用于箭。催化碎片不消耗；累计原料为紫水晶碎片8、骨头4、铜锭2，加上制鸣骨所需骨头3和铜锭3，再加盾牌直接材料。

路线优势来自招架、诱导和路径选择。默认不做持续加攻光环，也不把所有生物变成听见声音就无条件服从。
