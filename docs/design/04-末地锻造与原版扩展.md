# 末地锻造与原版物品扩展

## 1. 界髓矿与界铸装备

界髓矿填补末地的采矿成长：矿体埋在外岛内部，产出新材料，在锻造台升级已经投入资源的护甲和工具。原版末地石不变成处处可见的发光矿墙。

### 生成与采集

- 设计生成区为距原点水平半径1000格以外、Y32–72的末地岛体，偏向Y56；只替换末地石，不在空气中悬空生成。
- 对该高度范围至少有128块末地石的区块进行一次生成机会，45%概率生成1–3块；过滤前期望0.9块/有效区块，实际需统计。
- 矿体应埋藏，不刻意暴露于大面积空气；位置不合格即跳过，不无限重试。
- 需要下界合金镐或目标版本认定的同级工具。掉落自身，火焰和普通爆炸不会把矿体/掉落物廉价摧毁；时运不增加数量。
- 新矿默认只出现在新生成区块；不自动改写既有岛屿。老地图可通过Boss的少量碎屑掉落继续成长，另提供由服主主动触发的区域补生工具作为未来工作，不在本阶段执行。

### 配方与升级

| 编号 | 位置 | 输入 | 输出 |
|---|---|---|---|
| X01 碎屑冶炼 | 熔炉/高炉 | 界髓矿1 | 界髓碎屑1；10秒/5秒，燃料另计 |
| X02 界髓锭 | 工作台，无序 | 界髓碎屑4、紫水晶碎片4、龙精粹1 | 界髓锭1 |
| X03 首份界铸纹板 | 工作台，无序 | 裂界纹章1、界髓锭1、钻石4、末地石3 | 界铸纹板1 |
| X04 复制纹板 | 工作台 | 界铸纹板1、钻石7、末地石1 | 纹板2；消耗输入纹板，净增1 |
| X05 界铸升级 | 锻造台 | 纹板1、原下界合金装备1、界髓锭1 | 对应界铸装备1；纹板与锭消耗 |

界铸纹板还可作为末地探索战利品设计，但首版的X03是确定可取得的保底路径，不依赖箱子概率。裂界纹章来自失巢龙裔。

### 升级收益

v0.2外观与槽位要求：界铸保留原版下界合金轮廓和各部位比例，材质明显转为紫黑、深紫和紫晶色；升级装备约65–75%的可见金属面使用紫色系，关节保留黑紫，少量浅紫裂纹突出末影特征。不得仍以黑灰为主只点几条紫线，也不做巨大肩甲或角冠。四件护甲仍是头盔/胸甲/护腿/鞋子，绝不归入四个饰品栏；工具和剑仍为手持物。

| 类型 | 收益 | 明确保留/限制 |
|---|---|---|
| 四件护甲 | 各自耐久×1.25、韧性+0.5 | 基础护甲与击退抗性不增加；整套韧性只额外+2 |
| 镐、斧、锹、锄 | 耐久×1.25、合适工具挖掘速度+10% | 不获得连锁挖掘、不改变可采集等级的版本规则 |
| 剑 | 耐久×1.25、基础攻击+1 | 攻速保持原值，不额外附赠范围攻击 |

原附魔、自定义名、纹饰及其它合法可迁移数据需要继承，损耗耐久按比例保留。升级不会免费把濒坏装备修满，也不允许输出两件。

以当前常见下界合金基础数值为设计标尺，四件界铸护甲的明确目标如下；实现时先读取目标版本实际材料值，耐久统一向上取整，避免凭旧版常量猜API。

| 原生部位 | 护甲 | 韧性 | 单件击退抗性 | 目标耐久 |
|---|---|---|---|---|
| 头盔 | 3 | 3.5 | 0.1 | ceil(407×1.25)=509 |
| 胸甲 | 8 | 3.5 | 0.1 | ceil(592×1.25)=740 |
| 护腿 | 6 | 3.5 | 0.1 | ceil(555×1.25)=694 |
| 鞋子 | 3 | 3.5 | 0.1 | ceil(481×1.25)=602 |

合计护甲20、韧性14、击退抗性0.4。没有另加隐藏的百分比全伤减免。工具/剑以原耐久2031为例升级到2539；剑的设计目标基础攻击8→9，攻速不变。

路线装备本身已有独特动作，不统一转成界铸物品；它们通过各自专精成长。这样常规原版毕业装备与路线装备并存。

## 2. 真正单物品永续用品

永续用品不需要补充弹药或燃料，使用次数无限；平衡来自取得阶段、共同冷却和用途边界。两个物品都不可堆叠，正常死亡仍遵循服务器物品掉落规则。

### 配方

| 编号 | 输入 | 输出 | 位置 |
|---|---|---|---|
| X06 永续核心 | 裂界纹章1、界髓锭2、龙精粹2、回响尘2、凝潮珠2 | 永续核心1 | 工作台，无序 |
| X07 巡航焰匣 | 永续核心1、普通无烟火之星且飞行时间1的烟花火箭1、龙精粹4、幻翼膜2、烈焰棒1 | 巡航焰匣1 | 工作台，无序 |
| X08 缚界珍珠 | 永续核心1、末影珍珠4、回响尘2、凝潮珠2 | 缚界珍珠1 | 工作台，无序 |

每个永续核心的锻造材料包含8块界髓矿对应的碎屑，且需要一次失巢龙裔的纹章。龙蛋即使无限，也不能替代这些材料。核心在合成后转入物品本体，不返还，不允许两个输出共享同一核心。

### 巡航焰匣

- 鞘翅滑翔时右键使用，提供等同设计目标“飞行时间1”的普通助推；具体推力曲线沿目标版本的原生火箭路径验证。
- 每玩家共同冷却1.5秒；左右手交换、多持有几件或重连均不能绕过。
- 不带烟火之星，不造成烟花爆炸伤害，不能作为弩的攻击弹药；在地面可播放一次简短装饰火花，仍占冷却。
- 不额外增加鞘翅最高速度，不提供自动驾驶或悬停。
- 默认燃烧/尾迹为简洁低密度效果；粒子设置低时有更轻的表现。

它替代长期出行中的弹药携带，普通烟花仍承担前中期与战斗烟花的用途。

### 缚界珍珠

- 每次投掷本体保留，只产生一枚投射物；每玩家共同冷却12秒，且同时最多有1枚未结束的缚界投射物。
- 投射物最长存在15秒；超时或被合法取消后消失，不生成第二个可拾取本体。
- 保留珍珠传送的正常伤害路径，设计基准为5点原始伤害；不免费取消摔落/自伤，相关原版附魔按实际版本验证。
- 同一维度内使用，不穿越世界边界；落点要求完整身体空间，附近1格内没有合法点则失败，冷却仍保留。
- 不强制加载远处目标区块、不作为跨服传送、不提供无限穿墙。服务器取消传送的逻辑需要在实现中尊重。

## 3. 原版盾牌与弓弩扩展

第一版给原版盾牌三个互斥改造，回声盾等路线专用装备不能再叠加这些改造。

| 编号 | 配方或锻造输入 | 结果 |
|---|---|---|
| V01 遗珍改造纹板 | 紫水晶碎片1、纸4、铜锭4 → 纹板1 | 常规可再制造纹板，锻造时消耗 |
| V02 铁箍件 | 铁锭4、皮革2 → 铁箍件1 | 给盾牌增加耐久的改造件 |
| V03 偏转件 | 鸣骨1、铁锭2、紫水晶碎片2 → 偏转件1 | 精准偏转改造件 |
| V04 破阵件 | 缚龙锭1、铜锭2、皮革2 → 破阵件1 | 蓄势盾推改造件 |
| V05 盾牌改造 | 纹板1、原版盾牌1、上述一种改造件1 | 原盾牌附加对应改造，数据保留 |
| V06 快取弦 | 线3、回响尘1、铜锭1 → 快取弦1 | 弓改造件 |
| V07 弓改造 | 纹板1、原版弓1、快取弦1 | 蓄力时间−10%，箭矢最大基础伤害−10% |
| V08 驻射架 | 潮铸铜1、铁锭2、皮革1 → 驻射架1 | 弩改造件 |
| V09 弩改造 | 纹板1、原版弩1、驻射架1 | 站定0.8秒后的下一次主箭伤害+10%，装填时间+15% |
| V10 侦照箭 | 光灵箭4、回响尘1 → 侦照箭4 | 命中敌对生物提供4秒标记，默认不标记玩家 |
| V11 潮沫箭 | 普通箭4、凝潮珠1、玻璃瓶1 → 潮沫箭4 | 熄灭被命中实体上的普通火焰，敌对目标减速10%持续1秒；不放水 |

铁箍盾：最大耐久+25%，举盾时再额外降低5%移动速度。偏转盾：举盾开始0.2秒内可偏转1枚普通箭，冷却8秒，反射伤害上限8。破阵盾：格挡3次有效近战得到一次盾推，潜行重新举盾后对2格锥形范围造成3点伤害并轻推，冷却10秒。

一次攻击的多个投射物不能为破阵盾算多次充能；持续区域伤害不反复叠层。驻射架的多重射击只给主箭加成。更换改造需重新支付纹板和改造件，原改造不返还。

## 4. 磁石从路标变成据点工具

保留原版罗盘绑定；扩展只在玩家主动安装配件后生效。不会自动把所有磁石变成吸物器。

| 编号 | 配方 | 功能 |
|---|---|---|
| L01 磁引环 | 铁锭4、铜锭2、回响尘2、紫水晶碎片1 → 磁引环1 | 安装到磁石，启用受限吸物 |
| L02 远征罗盘 | 罗盘1、回响尘2、凝潮珠2、铜锭4 → 罗盘1 | 保存最多3个手动命名的磁石点，循环选择 |
| L03 稳定环 | 缚龙锭1、鸣骨1、潮铸铜1、紫水晶碎片4 → 稳定环1 | 安装在绑定的龙印磁石上，龙印吟唱缩短2秒，最低4秒 |

磁引环默认半径6，要求视线通畅，最多每秒转运4个物品实体到相邻可接收容器；每份紫水晶碎片运行16分钟。服从物品原生拾取归属，不打开远处箱子、不吸玩家/经验/投射物。

远征罗盘显示选中锚点名称、维度和距离，不提供自动传送。原磁石被破坏时显示失效，不能继续当作有效据点。每次扫描只使用已加载区块，不用吸物器强制加载基地。

## 5. 信标新增丰饶、匠心与庇护

信标保留原有主/副效果选择。完整四层信标可安装一个附加核心，并使用对应路线材料作为持续燃料；一次只启用一种额外能力。核心可拆回，已消耗燃料不返还。

| 编号 | 核心配方 | 燃料 | 新效果 |
|---|---|---|---|
| B01 丰饶核心 | 海洋之心1、金胡萝卜4、金块2、凝潮珠2 | 凝潮珠1/20分钟 | 每10秒恢复1饥饿点和2饱和度，遵守食物/饱和度上限 |
| B02 匠心核心 | 回响碎片1、回响尘4、铁块4 | 回响尘1/20分钟 | 合法耐久损耗有15%概率免除一次，与耐久附魔依次结算 |
| B03 庇护核心 | 龙精粹4、缚龙锭2、金苹果2、幻翼膜1 | 龙精粹1/20分钟 | 有效坠落伤害降低20%，每玩家15秒冷却；不处理虚空 |

丰饶采用低频、明确可见的饱食脉冲，不每tick反复施加高等级饱和。满饥饿时仍可逐次恢复缺少的饱和度，不突破当前食物值允许的上限。

附加效果作用范围取当前有效信标范围；纸面测试基准为水平50格，垂直范围随选定版本原生信标核定。失去光束、完整基座条件或燃料时停止追加效果。默认所有范围内玩家均可受益，同类核心不叠加。

其它可选效果：夜视和水下呼吸列为后续开关，不在首版同时堆到一个核心上。默认不提供无限抗性高等级、力量叠加或全世界饱和。

## 6. 永续物品总成本示例

制作一个永续核心，直接需要裂界纹章1、界髓锭2、龙精粹2、回响尘2、凝潮珠2。两个界髓锭又需要界髓碎屑8、紫水晶碎片8、龙精粹2。

因此一件巡航焰匣累计至少使用：界髓碎屑8、紫水晶碎片8、龙精粹8、回响尘2、凝潮珠2、裂界纹章1、普通合格火箭1、幻翼膜2、烈焰棒1。缚界珍珠累计至少使用：界髓碎屑8、紫水晶碎片8、龙精粹4、回响尘4、凝潮珠4、裂界纹章1、末影珍珠4。

上述不包含建设三种工作台的成本；可以由同伴共享已有工艺台，也可以交易材料，不要求每位玩家重做全部基础设施。
