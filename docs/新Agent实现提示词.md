# 新Agent实现提示词

以下整段可复制到新任务。它要求实现LynxRelics，不要求修改LynxTools/LynxTags。

```md
在 E:\Projects\Minecraft\LynxRelics 实现独立内容Mod LynxRelics，工作名“遗珍复苏”。先读AGENTS.md和README，再读docs/design/00至08以及docs/art/3D制作计划.md。v0.2是当前设计，06/07/08覆盖旧版冲突条目。不要仅输出另一份计划，要按阶段持续实现和交付源码、模型、贴图、动画、可用JAR与验证结果。

一、平台与边界
- 优先当前Minecraft Java 26.3/Fabric环境，JDK25；核对实际可用API与工具链，不能照搬其它版本签名。
- 这是双端内容Mod，与LynxTools管理/认证和LynxTags名牌独立，不修改这两个兄弟项目的已有工作。
- 玩家名牌下方的白色HP数字和红心由原任务在LynxTools/LynxTags单独实现，不在LynxRelics里再做一套重复渲染或同步。
- 用户的Elytra Slot实际文件为 E:\Minecraft\Lunar\mods\fabric-26.3\elytra-slot-1.2.jar，mod id=elytra-slot。先检查实际文件与接口，不把同名Curios/Trinkets项目当成它；不得未经需要强加这些库。
- 不操作生产服务器，不自动commit/push/发布。保留现有文档、图片和用户变更；不重置世界。

二、装备硬约束
- 原生四护甲槽：原版护甲照常使用，本Mod新增的只有“下界合金→界铸”的头盔/胸甲/护腿/鞋子放在这里。
- 界铸保留原版下界合金轮廓，约65–75%可见金属面用紫黑/深紫/紫晶主色，配浅紫裂纹；不能仍然黑灰为主只点几条紫线。不做巨大肩甲、角冠或整套异版型替换。
- 界铸护甲不归入Necklace/Cloak/Belt/Gauntlet。工具和剑依旧是手持物。
- 新增Necklace、Belt、Gauntlet、Cloak各一个饰品格。鞘翅仍使用Elytra Slot独立格，不能与Cloak抢同一槽或重复结算飞行。
- 龙、回响、潮汐各四件饰品，允许混搭；饰品基础护甲/韧性/击退抗性均为0。
- 龙系：项链负责归巢，腰带燃息40→50，手甲负责龙息技能，披风负责一次扑翼/滑翔转向修正。
- 回响：项链延长储响/声源，腰带负责潜行消音，护手负责精准招架，披风受击留短暂调查残响。
- 潮汐：项链反射普通箭，腰带潮势100→120并供额外空气，护手潮引，披风条件潮罩。
- 每件具体伤害、冷却、消耗、耐久、2/4件套及互斥以第06章逐项实现，不额外叠隐藏属性。
- 死亡、重生、keepInventory、重连、维度切换、Shift点击、背包满格、鞘翅损坏与修复必须验证，避免复制/丢失饰品。

三、玩法范围
- 完成龙精粹、回响、潮汐三路线。龙蛋按可量产物处理，催化可回收、增效有限；不以“龙蛋唯一”平衡。
- 实现三工艺台、完整精炼/专精配方、路线武器/装置、七种新生物和明确成长顺序。配方按编号，扣料/返瓶/输出满格不可吞料复制。
- 界髓矿只默认生成于新的末地外岛区块；锻造升级保留合法附魔、名称、纹饰与损耗耐久比例。
- 界铸基础目标：护甲3/8/6/3、单件韧性3.5、单件击退抗性0.1，耐久按原值×1.25向上取整；工具速度+10%，剑基础攻击+1，攻速不变。实现前核对目标版本基础值。
- 巡航焰匣和缚界珍珠是真正单物品不耗本体/不补弹药，分别有1.5秒/12秒共同冷却；珍珠保留正常传送伤害。不能换手/重连绕过。
- 完成盾牌/弓弩改造、磁石配件、信标丰饶/匠心/庇护核心，遵守第04章收支及叠加上限。

四、原版末影龙强化
- 最大HP固定3000，原生BossBar实时显示真实剩余/最大值和阶段；不能用另一个假龙替代。
- 第07章的三个阶段、预警招式、自召最多3枚水晶、召回次数/生命期/回血预算、战利品都实现。
- 原版复活/出口门/杀龙进度保留；水晶和阶段必须可保存恢复，不能重载刷血/刷奖励。
- 新招式伤害和实体数量有上限，不靠大规模粒子遮挡预警，不用改全局gamerule处理局部效果。
- 失巢龙裔仍是独立360HP路线Boss，不能与3000HP原版龙混成同一遭遇。

五、附魔
- 实现第08章16种附魔及书籍工艺，按目标物品和互斥表处理；不自动把原版保护类叠到四个饰品格。
- 同一命中的余响/反射/技能不能递归触发；冷却、资源容量、减伤与窗口上限按文档。
- 鞘翅附魔读取实际提供滑翔能力的Elytra Slot物品，不能只看胸槽。

六、美术由你完成
- 已有assets/concepts概念图；它们不是可直接导入的模型。
- 交付可编辑bbmodel、PNG贴图、骨骼/动画及目标运行格式；按3D计划先灰模和尺度验证，再细化UV/动画。
- 第一轮验证萃取台、龙喉手甲、裂界之刃、回声盾、潮锋戟，再补四饰品套、末地装备、新生物、强化龙招式表现。
- 界铸严格保持原版下界合金形体，使用最新紫色材质方向，不把旧概念图中夸张装甲或初版过少的紫色当最终造型。

七、实施和验证
- 先做可运行最小闭环：四饰品格+一种工艺+一件技能+Elytra共存，再扩三路线、末地锻造、Boss和附魔；不要把只完成第一阶段说成全部实现。
- 用当前实际API。服务端拥有属性、冷却、资源、伤害、制造与掉落的权威，客户端只发送动作意图并渲染。
- 保留原版功能、普通按键与镜头配置，所有新增关键参数可配置。别引入无关经济/职业/插件框架。
- 使用与改动风险匹配的检查。报告区分静态/构建/单测/隔离服/真实客户端/生产，不编造未执行场景。
- 每阶段记录已完成、产物路径、验证证据、未解决问题；持续推进全部用户范围。最终提供源码、双端JAR、模型源文件、配方/配置说明和准确验证边界。
```
